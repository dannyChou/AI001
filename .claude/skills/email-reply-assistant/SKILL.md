# Email 回覆助手

## Description
當使用者貼上客戶來信內容，或說「幫我回覆這封信」、「回覆客戶」時，自動分類信件並產出專業回覆草稿。

## Trigger
- 使用者貼上一封 Email 內容
- 使用者說「幫我回覆信」「回這封信」「回覆客戶」

## Steps

### Step 1：讀取信件
讀取使用者提供的信件全文。如果沒有提供，請使用者貼上信件內容。

### Step 2：分類信件
根據內容判斷信件類型：
- **詢價**：客戶問產品價格、服務方案、報價
- **客訴**：客戶反映問題、表達不滿、要求退款
- **一般問題**：其他問題、合作洽談、資訊詢問

### Step 3：撰寫回覆
根據信件類型套用以下風格：

**詢價回覆：**
- 感謝來信詢問
- 簡述產品/服務重點
- 附上報價或引導下一步
- 語氣：專業、積極

**客訴回覆：**
- 致歉並表達重視
- 確認問題內容
- 提出解決方案或下一步處理方式
- 語氣：同理、負責

**一般問題回覆：**
- 感謝來信
- 直接回答問題
- 如需更多資訊，說明取得方式
- 語氣：友善、簡潔

### Step 4：格式化輸出
輸出格式：
```
【信件類型】：詢價 / 客訴 / 一般問題
【判斷依據】：一句話說明為什麼這樣分類

---

主旨：Re: {原信主旨}

{收件人稱呼}，您好：

{回覆內容}

{署名}
```

## Rules
- MUST：語氣保持專業友善，使用正式書信格式
- MUST：回覆長度控制在 150-300 字
- MUST：明確告知下一步行動（例如「我們將在 2 個工作天內回覆報價」）
- NEVER：不自行承諾折扣、賠償金額或交期
- NEVER：不洩漏公司內部資訊
- NEVER：不使用過於口語化或輕浮的用語

## Example

**使用者輸入：**
```
請幫我回覆這封信：

王經理您好，
我們公司近期有意導入 AI 客服系統，想了解貴公司的方案內容與費用。
麻煩提供相關資料，謝謝。
陳先生
```

**AI 輸出：**
```
【信件類型】：詢價
【判斷依據】：客戶詢問方案內容與費用

---

主旨：Re: AI 客服系統方案詢問

陳先生，您好：

感謝您對我們 AI 客服系統的興趣！

我們目前提供三種方案（基礎版 / 專業版 / 企業版），
可根據貴公司的客服量與需求彈性搭配。

我將在 2 個工作天內寄送完整方案說明與報價給您，
同時也歡迎安排線上 Demo，讓您實際體驗系統功能。

如有任何問題，隨時與我聯繫。

祝 商祺
{你的姓名}
{公司名稱}
```

# 每日經文早安賀卡 · Claude Code 專案指引

這個專案用來產生「**書籤式每日經文早安賀卡**」：以當日聖經經文為核心，寫給**非基督徒**讀者，語氣親切白話、不說教；配一張手繪 SVG 插圖（**淡化基督風＋美式鄉村自然風**），最後渲染成 retina PNG，並保留可再編輯的 HTML。

Claude 在本專案接到「做今天的卡片／做 X 月 X 日的卡片／套上次的程式」這類需求時，一律依本檔流程處理。**所有面向讀者的文字一律使用繁體中文。**

---

## 目錄結構

```
daily-scripture-card/
├── CLAUDE.md                     ← 本檔（專案規則，Claude 自動讀取）
├── README.md                     ← 環境安裝與使用說明
├── .claude/commands/card.md      ← 斜線指令 /card
├── assets/card_template.html     ← 可重用樣板（含經節區塊）
├── scripts/render_card.py        ← Playwright 渲染 HTML→PNG
├── scripts/verify_pixels.py      ← 像素統計備援驗證
├── cards/                        ← 產出的 HTML（card_YYYYMMDD.html）
└── images/                       ← 產出的 PNG（morning_card_YYYYMMDD.png）
```

---

## 標準工作流程（五步，中間不要停）

1. **定位經文**：從使用者提供的讀經進度表，找出目標日期對應的經文段落（書卷＋章＋節）。
2. **提煉主題**：讀懂經文核心，轉成一個非基督徒也能領受的**生活化主題**（見「內容原則」）。
3. **撰寫 HTML**：`cp assets/card_template.html cards/card_YYYYMMDD.html`，替換日期、標題、副標、（經節區塊）、三段內文、引言、頁尾，並置換 SVG 插圖。
4. **產圖前檢查＋渲染**：先用 grep 掃內文確認全繁中，再用 `scripts/render_card.py` 渲染成 PNG。
5. **驗證＋回報**：`view` 看圖或用 `scripts/verify_pixels.py` 統計驗證，確認插圖正常；回報使用者。

---

## 第一步：定位經文

進度表每行格式類似：`8月20日 (四) 尼希米記 13 : 1 ~ 14`。找出目標日期那一行取其經文範圍。若進度表沒有該日，先向使用者確認。這個範圍之後頁尾要用（格式見下）。

---

## 第二步：從經文提煉主題

目標是讓**沒有信仰背景的人**也能被觸動，而不是被說教。

1. **先讀懂經文核心**（例：潔淨聖殿＝把喧鬧算計請出去、為心留安靜）。
2. **轉成生活化標題**（白話、非宗教語彙，例：「為心留一方安靜」「各修一段牆」）。
3. **從人人有共鳴的經驗切入**：第一段幾乎不談信仰，先描述普遍的人性處境。
4. **受難／沉重經文溫柔導向盼望**：不寫血腥或身體傷痛細節，改從「有人默默承擔」「你並不孤單」切入。
5. **復活／歡慶段落語氣轉亮**：用明亮版配色（見下）。
6. **認罪／省察類經文**：務必寫成溫柔、建設性的自我接納，**不強化負面自我苛責**（明說「不必苛責自己」）。

### 直白信仰表達原則（務必維持）

不要用「古老的智慧」這類迂迴說法，要**直白正直地讓人知道這出自聖經與基督教信仰，但不激進、不施壓**：

- 明說出處：「**聖經的尼希米記裡……**」，直接稱呼**耶穌**、**神**。
- **引用經文原句**（簡短、加引號），關鍵詞可用 `<strong>` 強調。
- 誠實呈現經文事實（含人的失敗），不美化、不迴避。
- **結尾用「邀請」而非「要求」**：以「若你好奇……，歡迎有一天翻開聖經裡的○○記……」收束，把決定權留給讀者。

## 第三步：撰寫 HTML（版型規格）

以 `assets/card_template.html` 為基底，只替換內容，**不要改動版型 CSS**。

- **書籤直式**：`.bookmark` 寬 640px、米白紙、圓角、1.6px 虛線內框。
- **字型**：`Noto Serif CJK TC`（襯線，內文）＋`Noto Sans CJK TC`（無襯線，日期／副標／頁尾）。
- **色票**：`--paper:#F7F3EA`、`--ink:#3E3A33`、`--ink-soft:#7A756B`、`--sage:#8FA382`、`--wheat:#E3C282`、`--barn:#9A6B52`。
- **內容結構（由上而下）**：
  1. `.art`：SVG 插圖
  2. `.date`：`2026 / 08 / 20`（字距寬、置中，下有短分隔線）
  3. `h1`：中文主標題
  4. `.subtitle`：英文副標（全大寫、字距寬）
  5. `.verse`（選用）：**標題後經節區塊**，見下
  6. `p.body` × 3：三段內文
  7. `.quote`：左邊框斜體金句
  8. `.footer`：細線 + 英文經文出處 + 祝福語

### 三段內文的固定節奏

- **第 1 段**：從普遍人性處境切入，先不談信仰。
- **第 2 段**：帶入聖經敘事「聖經的○○記裡……」，引用原句，直白而溫柔。
- **第 3 段**：拉回讀者的「今天」（用當天星期，如「週四的清晨」），給溫柔的具體行動，並以邀請收尾。

### 標題後經節區塊 `.verse`（選用）

當使用者要求「在標題後放入經文」時，於副標下方放一個淡米色圓角框，內含當日經文裡 **1–2 節**切合主題的經句 + 出處：

```html
<div class="verse">
  <div class="txt">「那日，眾人獻大祭而歡樂……<br>耶路撒冷中歡樂的聲音聽到遠處。」</div>
  <span class="ref">尼希米記 12 : 43</span>
</div>
```

放此區塊時 `.subtitle` 的 `margin-bottom` 用 **28px**；不放時改回 **40px** 並刪除區塊。經句務必全繁中、加引號。

### 頁尾 `.footer`

- `.en`：**當日經文出處**，格式 `NEHEMIAH 13 : 1 – 14`（書卷英文大寫、全形間距、破折號 `–`；跨章如 `NEHEMIAH 9 : 38 – 10 : 39`）。
- `.bless`：**以「願神祝福你：」開頭**，接八字左右對稱短句。

### 標題過長處理

- 9–10 字：`h1` `font-size:38px; letter-spacing:.08em`。
- 12 字：`font-size:34px; letter-spacing:.04em`（實測仍可單行）。

### 常見陷阱（務必避免）

- **內容區絕不用 Markdown 星號** `**text**`（會照字面顯示）；強調一律 `<strong>`。
- 內文、經節、祝福語**全繁體中文**，不可混入英文單字（例：曾誤把「今天」寫成 today）。
- SVG 屬性值若打錯（出現非法字元），Chromium 仍會渲染但該元素消失 → 產圖後務必驗證。

## 第四步：插圖（SVG 慣例）

插圖是 `.art` 內一段 inline `<svg viewBox="0 0 440 300">`，風格柔和溫潤。

### 必備的「系列一致元素」（讓整套看起來一致）

- **晨光＋淡化十字**：一輪柔和太陽（radial-gradient 光暈＋實心圓心），中央疊一組**極淡的十字光線**（兩條淺黃低透明度直線交叉）——唯一、最含蓄的信仰記號。
- **木籬笆**（左下）、**野花小草**、**飛鳥**（`q` 曲線簡筆）、**落葉一枚**（旋轉空心橢圓）、**地面線**。

### 主體圖像＝當日主題的具象化

除系列元素外，主體要呼應當天主題。尼希米記「城牆重建」弧線用過的對應（供參考、不必重複）：

| 主題方向 | 主體圖像 |
|---|---|
| 為破碎心疼 | 殘破石牆＋提燈＋新芽 |
| 開口前禱告 | 推開的拱門＋門後光路 |
| 先看清再動手 | 夜間殘牆＋提燈＋測量繩杖 |
| 各修一段牆 | 分段城牆＋泥鏟木桶 |
| 一手做工一手守望 | 半成城牆＋泥鏟＋守望旗幟 |
| 別加重擔（公義） | 天平＋穀物＋鬆開的布袋 |
| 忠信可託付 | 完工城牆＋雙扇門閂＋守夜燈＋鑰匙 |
| 每個名字被記得 | 攤開名冊＋被燈照亮的金色名字行 |
| 說不清仍有位置 | 亮燈暖窗小屋＋石徑＋微開的門 |
| 喜樂是力量 | 木臺上被光照亮的律法書＋光束＋葉棚 |
| 低頭再站起 | 低垂花＋露珠＋昂首向光的花 |
| 回頭滿是恩典 | 蜿蜒回望小路＋沿途由近到遠的小提燈 |
| 化感動為承諾 | 攤開約書＋簽名＋紅色印章＋羽毛筆 |

| 辛苦後慶祝 | 完工城牆＋慶祝旗幟＋豎琴音符＋香煙 |

**苦難／新生母題**：受難段落用「暗色調＋一線光＋一株新芽」；復活／歡慶用明亮版。

### 明亮版配色（復活／歡慶段落）

- `body` 背景：`radial-gradient(1200px 900px at 30% 18%, #FBF3D8 0%, #F0EBDF 45%, #E9E4DA 78%)`
- `.bookmark` 背景：`#F8F5EC`
- 太陽：`#F9E58C` 圓心、`#FDEFB0` 光暈，加放射狀晨光線
- `.quote` 左邊框：`#D8C58A`

## 第五步：渲染與驗證

### 產圖前檢查（全繁中）

```bash
grep -oE 'class="(body|txt)">[^<]*' cards/card_YYYYMMDD.html | grep -iE '[a-z]{2,}' | grep -vE 'body|txt|br' || echo "內文與經節無英文夾雜"
```

### 渲染

```bash
python3 scripts/render_card.py cards/card_YYYYMMDD.html images/morning_card_YYYYMMDD.png
```

（Playwright + Chromium headless，viewport 900×1200、device_scale_factor=2，等 800ms，對 body 截圖，產出約 1800px 寬。）

### 驗證（務必自行確認圖可正常顯示）

**第一優先：直接看圖。** 用 `view` 開啟 PNG，確認版面、文字、插圖正常；再裁切上方約 26–30%（水平 15%–85%）放大檢視插圖細節。

**備援：像素統計。** 視覺預覽帶不回畫面時（偶爾發生），用統計確認圖非空白：

```bash
python3 scripts/verify_pixels.py images/morning_card_YYYYMMDD.png
```

健康值參考：unique_colors 約 8,000–9,800（明亮版可破萬）、art_marks > 1000、body_text > 800、footer > 100。可另針對主體特徵色抽樣（提燈暖光、石牆灰、花的粉紫、晨光亮黃）。判定 OK 即完整，並在回報時據實說明「這次改用像素統計覆核」。

### 命名慣例

- HTML：`cards/card_YYYYMMDD.html`
- PNG：`images/morning_card_YYYYMMDD.png`

---

## 回報使用者時

產圖後給一段簡短說明，涵蓋：**經文對應**（哪段、核心信息、主題）、**（若有）經節區塊說明**、**信仰表達**（如何直白引用又不施壓）、**視覺設計**（主體圖像＋系列元素）、**驗證情況**（若用像素備援據實說明），並可預告隔天經文的可能主題方向。語氣自然、不冗長。

# 靈修書籤重製與主題插圖生成

## 這個 skill 在做什麼

把一份靈修內容（來自參考圖片或純文字），整理成一張**直式長條**的書籤圖，並且重新設計最上方的主題插圖。

核心價值不在排版，而在三件事：
1. 把冗長的靈修文字**濃縮成一個核心信息**，而不是隨便刪字。
2. 確保**經文、人名、章節完全正確**。
3. 讓上方插圖**由當天主題推導出來**，而且明顯不同於前幾張。

---

## 兩種模式

**重製模式（有參考圖片）**
先讀圖，抓出原有的資訊架構與所有文字，保留閱讀順序，只重做插圖與文字濃縮。除非使用者明講，不要更動區塊順序。

**新製模式（只有文字）**
使用者只給經文段落或靈修內容時，直接套用下方「標準版型」建立資訊架構，其餘流程完全相同。

兩種模式都同樣適用於書籤、靈修卡、禱告卡、直式海報。

---

## 標準版型

由上而下固定為：

```text
┌─────────────────────┐
│      主題插圖        │
│        日期          │
│       主標題         │
│     英文副標題       │
│     主題經文區       │
│     內容區 1（生活）  │
│     內容區 2（聖經）  │
│     金句／引用       │
│     今日應用         │
│     結語             │
│     經文範圍         │
│     祝福語           │
└─────────────────────┘
```

比例上維持**直式長條、書籤感**（建議 1:3 到 1:3.5，例如 1000×3000 px）。

---

## 執行順序

```text
讀圖或讀文字
↓
擷取日期／標題／經文／各段落
↓
萃取當日核心主題
↓
濃縮各區文字（非主題經文區 ≤ 60 字）
↓
校對經文、人名、章節、錯別字
↓
設計視覺隱喻 → 人物與動作 → 構圖
↓
比對前幾張，確認差異夠明顯
↓
寫出完整生圖提示詞
↓
生成整張書籤圖
↓
檢查文字正確性、留白與比例
↓
交付，並附上本次插圖的一句話特徵摘要
```

---

## 一、萃取核心主題

不要直接刪字。依序讀：**標題 → 主題經文 → 聖經故事 → 核心衝突 → 轉折 → 今日應用**，然後回答一個問題：

> 「今天這篇靈修，最想讓讀者記住的是什麼？」

答案就是核心信息。後面的文字濃縮與插圖設計，全部從這一句推導出來。這一步做錯，後面做得再漂亮也沒用。

---

## 二、文字濃縮

除主題經文外，**每個內容區塊控制在 60 字以內**。

| 區塊 | 寫法 |
|---|---|
| 第一區：生活共鳴 | 聚焦一個日常情境、一種情緒、一個問題。不說教、不重複。 |
| 第二區：聖經故事 | 只留人物、困境、關鍵行動、轉折、核心意義。 |
| 金句／引用 | 一句就好，約 20～35 字。**不要把個人感想寫成聖經原文的樣子。** |
| 今日應用 | 回答「今天我可以做什麼？」具體、溫和、做得到。 |

語氣維持親切白話，讓沒有教會背景的人也讀得懂。

---

## 三、聖經正確性

這是不能妥協的部分，錯了整張圖就要重做。

- **主題經文**：使用者說「保留」時，**逐字保留，不得改寫、重譯或美化**。使用者後續另行指定文案時，以最新指定的文字為準。
- **人名**：以斯帖、末底改、哈曼、亞哈隨魯王這類容易混淆的名字，逐一核對，不可張冠李戴。
- **章節**：核對書卷、章、節與起訖範圍，並確認**正文引用**與**底部經文範圍**兩處一致。
- **情節**：不加入聖經沒有的情節。

---

## 四、上方主題插圖

### 4.1 由主題推導，不套模板

正確：讀懂經文 → 萃取核心信息 → 決定視覺隱喻 → 安排人物與場景 → 設計構圖。

錯誤：先畫固定的太陽＋山＋道路，再硬套今天的主題。

### 4.2 人物優先

插圖以 1～3 名人物為主體，人物是敘事的主角，不是點綴。**人物的動作要能直接表達主題**：

- 放下重擔 → 人物卸下背包
- 勇敢前行 → 人物跨過門檻
- 被接納 → 人物被伸手迎接
- 被記念 → 人物看著保存下來的信件
- 休息 → 人物放下手機坐下來
- 等候 → 人物安靜地等
- 說出真話 → 人物遞出信、坦誠對話
- 憂苦轉喜樂 → 人物從低頭轉為被擁抱、重新微笑

### 4.3 避免與前幾張重複（主要檢核項目）

先確認前幾張長什麼樣：使用者若沒提供，主動請他貼出最近 2～3 張的插圖，或用一句話描述。

**避免連續使用**：太陽＋地平線、山＋道路、長椅、柵欄、小屋／教堂、長桌、窗邊＋咖啡、聖經＋咖啡杯、單一大型物件置中。

**每次至少更換 3 項以上**：場景、主體人物、人物動作、視角、時間、空間、光源、象徵物、前景物件、背景結構、構圖重心。

系列的一致性來自**設計語言一致**（色調、字級層次、邊框、區塊形式），不是每天畫同一個畫面。

### 4.4 去宗教化

可以用：人物、家庭、房間、公園、市集、工作桌、行李、信件、植物、水、光、門、路、書本、日常用品、自然景色。

不要每張都依賴：十字架、教堂、聖經書本、禱告姿勢、大型神聖光環。宗教元素偶爾出現可以，但不能變成固定公式。

### 4.5 風格：卡通基督風＋文青風

要：手繪水彩感、米白／奶油色紙感底、低飽和的綠棕橘米色、細線條、柔和陰影、溫暖自然光、可愛但不幼稚、年輕人接受度高、簡潔乾淨。

不要：過度寫實、宗教宣傳感、幼兒卡通感、過度鮮豔、太多裝飾。

## 五、生圖提示詞

由圖像生成模型輸出整張書籤圖。生圖前先把提示詞寫完整，包含五段：

1. **畫布**：直式長條書籤、比例、米白紙質背景、整體風格關鍵字。
2. **上方插圖**：場景、人物數量與動作、視角、光源、象徵物、色調，並寫明「與 XXX 構圖不同」。
3. **文字內容**：依標準版型逐區列出實際文字，含日期、標題、副標題、經文與出處。
4. **排版**：字級層次、區塊間距、金句框樣式、留白控制。
5. **禁止項**：不要十字架與教堂、不要過度寫實、不要大片空白、文字不可溢出。

### 中文文字的處理

圖像生成模型畫中文字經常出現錯字、缺筆、糊字，這是已知限制。因此：

- 生成後**逐字核對**畫面上的每一段中文，尤其是經文、人名、章節數字。
- 出現錯字時，**重生成，不要將就**。
- 若同一段文字連續兩次都畫錯，改用備援作法：**請圖像模型只生成上方插圖（無文字底圖），文字層另外以 HTML/CSS 或 SVG 疊上後再輸出 PNG**。這樣文字 100% 正確，插圖仍由模型生成。使用者若偏好整張生成，仍以整張為主，備援只在必要時啟用。

---

## 六、留白與比例

產圖前後都要看：

- 上方插圖不能過度空曠。
- 中段各文字區間距一致。
- 底部不能因為文字變短而出現大片空白。
- **不為了填空白硬加無關內容**。

要調整時，依序處理：插圖高度 → 字級 → 區塊間距 → 金句框高度 → 整體比例。

---

## 七、檢核清單

### 產圖前（文字）

- [ ] 無錯別字，句子完整，用詞自然
- [ ] 沒有偏題、沒有重複
- [ ] 沒有把個人感想寫成經文
- [ ] 沒有聖經以外的情節
- [ ] 非主題經文區塊皆 ≤ 60 字
- [ ] 人名、書卷、章節正確
- [ ] 主題經文符合使用者指定文字

### 產圖後（視覺）

- [ ] 直式長條書籤
- [ ] 資訊架構清楚、順序未亂
- [ ] 插圖與主題高度相關
- [ ] 有人物，且動作正在表達主題
- [ ] 不是固定模板的變形
- [ ] 與前幾張有明顯差異（至少 3 項不同）
- [ ] 卡通基督風＋文青風
- [ ] 去宗教化
- [ ] 沒有過多留白、文字沒有溢出
- [ ] 畫面上的中文逐字正確
- [ ] 底部有經文範圍與祝福語

---

## 八、交付時附上

交付圖檔的同時，附上一句話的**本次插圖特徵摘要**（例如：「黃昏市集，母親牽著孩子回頭揮手，側視角，暖橘光」）。下一次製作時拿它來比對，就能避免撞圖，也不必每次都重新翻舊圖。

---

## 最高原則

> 先理解主題，再設計畫面；先確保經文正確，再追求視覺美感。系列要一致，但每一天的畫面必須有自己的故事。
